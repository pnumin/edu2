국방예산 웹 대시보드

사용 방법
1. index.html을 Edge 또는 Chrome에서 엽니다.
2. 부문과 회계구분 필터를 선택합니다. 모든 요약과 차트에 적용됩니다.
3. 상세 표에서 프로그램을 검색하거나 열 제목을 눌러 정렬합니다.
4. CSV 다운로드로 필터 및 검색 결과를 저장할 수 있습니다.

구성
- index.html: 대시보드 화면
- styles.css: 반응형 디자인
- app.js: 필터, 차트, 표, 다운로드 기능
- data.js: 원본 엑셀의 32개 상세 항목 데이터

서버 설치나 외부 인터넷 연결 없이 사용할 수 있습니다.
